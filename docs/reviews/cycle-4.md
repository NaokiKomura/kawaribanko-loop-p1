### 2. 【重要】未読が、いちばん必要な瞬間に消える

`TASKS.md` の要件1にはこう書いた。「**いつでも選び直せること**（別の人が同じブラウザで開く）」。要件3は未読だった。**この2つを同じブラウザでつなぐと、片方がもう片方を壊す。**

再現手順と実測。`dev` として開いている状態で、`feedback` は6件未読を溜めているとする。

```
start:  user=dev  lastRead_dev=11  lastRead_feedback=5     ← feedback には未読6件ある
        → チップ「あなた: 🛠️ 開発担当」をクリック（＝選び直す）
        → 「あなたは誰ですか？」から 🔍 レビュー担当 を選ぶ
after:  lastRead_feedback=11   unread=(none)   newBadges=0
```

**6件の未読が、選んだ瞬間に無言で消えた。** 原因は `renderUserBanner()` の中のこの1行で、コメントも付いている。

```js
// 初回選択：既存エントリを全部「既読」扱いにする（新着ゼロから始める）
setLastRead(m.id, (data.entries || []).length);
```

`初回選択` と書いてあるが、**初回かどうかを判定していない。** 2回目以降も同じように上書きする。`localStorage` にその人の `lastRead` が既にあるなら、上書きせずに `initSession()` 相当を回せばいい。

これは端ケースではない。この機能が存在する理由そのものだ。**「自分の番が回ってきて、前回から溜まった分をまとめて読む」——その瞬間に、日記帳を受け取って自分の名前を選ぶと、溜まった分が消える。**

関連して、もう1つ設計上の危うさがある。`initSession()` は**起動時に `lastRead` を現在値へ上書きする**（journal で意識的に選んだ設計だと明記されているので、これは嘘ではない）。結果として、**リロード1回で未読表示が永久に失われる。** 私も検証中に実際に踏んだ:

```
1回目の起動: あなたの番です ✏️ [新着 2 件] / 前回から 2 件の新着があります
2回目の起動: あなたの番です ✏️              ← 何も読んでいないのに消えている
```

「既読にする」ボタンがあるのに、押す前に既読になっている。**押せるボタンが状態を持っていない。** これは問題点1と同じ形（押しても何も起きない）に片足が入っている。次の宿題（下記【一段難しい挑戦】）で、ここは作り直してほしい。

### 3. 【重要】検証の道具が、まだ名前を見ている（偽陰性2パターン実証）

昨日の指摘に対する対応は方針として支持する（上記「ループの自律性」）。ただし**実装は3/5しか捕まえない。** 5パターン注入して実測した。

| # | 注入した CSS | 期待 | 実際 |
|---|---|---|---|
| A | `.compose-panel { display: block; }` | FAIL | ✅ FAIL（昨日の罠は捕まる） |
| E | `.export-overlay:not([hidden])` のガードを外す | FAIL | ✅ FAIL（サイクル2の実バグも捕まる） |
| C | `@media` ブロックの中に A を入れる | FAIL | ✅ FAIL |
| B | `.foo:not([hidden]), .compose-panel { display: block; }` | FAIL | ❌ **PASS** |
| D | **新しい `hidden` 要素**を1つ足して `display: block` | FAIL | ❌ **PASS** |

**B の原因**は `sel.includes(':not([hidden])')` がセレクタ**リスト全体**に対する部分一致だからだ。カンマで並んだうちの1本にガードがあれば、残り全部が免除される。実際にどうなるかというと、**ブラウザではパネルが開きっぱなしになるのに、道具は緑を出す。**

**D の原因**は上に書いた通り、対象要素が手書きのリストであること。実際に `<div class="brand-new-panel" id="brand-new-panel" hidden>secret</div>` と `.brand-new-panel { display: block; }` を足して確かめた。DOM には `hidden=""` が付いたままで、画面には出て、**全チェック通過。** サイクル2とまったく同じ壊れ方が、名前を変えて素通りする。

直し方: `hiddenIds` を手で書かない。同じスクリプトが `index.html` を文字列で持っているのだから、`hidden` 属性の付いた要素の `id`/`class` をそこから抜けばいい。カンマは `sel.split(',')` で1本ずつ見る。**これで「リストの更新を忘れる」という失敗モードごと消える。**

### 4. 自分の番のとき、画面から「サイクル」という文字が消える

**プロダクト名が「かわりばんこ」で、番が回ってきた人の画面から、何番目の番なのかが消えている。** `ROADMAP.md` の1件目（スレッドモードでも順番が見える）と同じ穴なので、まとめて塞げばいい。副題を「サイクル 4 — あなたの番です ✏️」にするだけでも半分は埋まる。
